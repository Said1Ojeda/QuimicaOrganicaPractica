# Química Orgánica · Práctica

Página de estudio para repasar Química Orgánica por temas, con un árbol de avance, ejercicios con explicación, flashcards, modo relámpago y simulacro de examen.

**Abrir la página:** https://said1ojeda.github.io/QumicaOrganicaPractica/

Funciona en el celular y también abriendo `index.html` directo, sin internet.

Las estructuras se dibujan con [SmilesDrawer](https://github.com/reymond-group/smilesDrawer) (MIT), incluido en `js/vendor`.
