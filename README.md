# Química Orgánica · Práctica

Página de estudio para repasar Química Orgánica en 11 temas, de alcanos a ácidos carboxílicos. Tiene un árbol de avance, ejercicios con explicación paso a paso, flashcards, modo relámpago y un simulacro de examen con cronómetro.

**Abrir la página:** https://said1ojeda.github.io/QuimicaOrganicaPractica/

Funciona en el celular y también abriendo `index.html` directo, sin internet. El progreso se guarda en el navegador.

## Estructura

```
index.html
css/estilos.css
js/app.js          interfaz y pantallas
js/motor.js        ejercicios, progreso y dibujo de moléculas
js/data/           un archivo por tema
js/vendor/         SmilesDrawer
```

Las estructuras se dibujan con [SmilesDrawer](https://github.com/reymond-group/smilesDrawer) (MIT).
